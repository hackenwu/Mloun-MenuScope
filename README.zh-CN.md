# Mloun MenuScope（WP 后台菜单管理）

按**角色或单个用户**隐藏、屏蔽、重命名、拖拽排序 WordPress 后台菜单，还能隐藏插件和隐藏用户 —— 全部在后台点选，不用改代码。

本仓库是免费版源码，与 [WordPress.org](https://wordpress.org/plugins/mloun-menroscope/) 上发布的代码完全一致。

- **环境要求**：WordPress 5.8+，PHP 7.4+
- **兼容至**：WordPress 7.1
- **授权**：GPLv2 或更高
- **设置位置**：**设置 → MenuScope**

## 解决什么问题

默认的 WordPress 后台把每个菜单、每个插件、每个用户都展示给所有人。给客户做的站点，这既是干扰，也是客服工单的来源。MenuScope 让你决定每种角色（或某个具体用户）真正看到什么，而且所有设置都可撤销。

## 功能

- **按角色/用户隐藏菜单** —— 菜单从侧边栏消失，但页面 URL 仍可访问。
- **按角色/用户隐藏并屏蔽菜单** —— 菜单消失，直接访问 URL 返回 403。
- **拖拽排序** —— 按角色/用户调整顶级菜单和子菜单顺序，子菜单在编辑器里可折叠。
- **重命名菜单** —— 给任意菜单或子菜单换一个显示名称（按角色/用户）。
- **隐藏插件** —— 插件从「插件」页面消失，该角色/用户无法停用、删除、更新，也无法用插件文件编辑器打开。可以隐藏 MenuScope 自己。
- **隐藏用户** —— 被隐藏的用户对其余人不可见：用户列表、作者下拉框都看不到，直接访问其资料页也不行；但他们本人可以正常登录和使用后台。可以隐藏自己。
- **用户设置优先于角色设置** —— 同一类设置（菜单/插件/重命名）只要给用户单独配置过，就完全覆盖其角色里的配置。

## 隐藏 vs. 屏蔽

| | 侧边栏菜单 | 直接访问 URL |
|---|---|---|
| **隐藏** | 移除 | 仍可打开 |
| **隐藏并屏蔽** | 移除 | 拒绝（403） |

不想让某个角色碰的东西（比如某插件的菜单）用「屏蔽」；只是想减少干扰用「隐藏」。

## 安装

1. 后台 **插件 → 安装插件** 搜索 "Mloun MenuScope"，或上传插件 ZIP，或把 `mloun-menroscope` 目录复制到 `wp-content/plugins/`。
2. 启用插件。
3. 打开 **设置 → MenuScope**。

## 使用方式

设置页分三个标签：

- **Menus（菜单）** —— 在 *Configure for* 里选一个角色或用户，然后开关可见性、选择隐藏/屏蔽、拖拽排序、重命名。
- **Plugins（插件）** —— 对某角色/用户隐藏指定插件。
- **Users（用户）** —— 对其他所有人隐藏指定用户。

设置按角色和按用户分别存储。想彻底撤销某个角色/用户的配置，在 *Configure for* 里点它旁边的 **Delete**。

## 安全设计

- 具备 `manage_options` 权限的用户始终能进入 MenuScope 设置页，插件不会把管理员锁在自己的设置之外。
- 屏蔽 WordPress 基础设施菜单（例如「设置」父菜单）时，对管理员会自动降级为「隐藏」—— 管理员可以把菜单藏起来，但永远不会把自己 403 挡在 `wp-admin` 之外。
- 卸载插件会清除其设置，多站点网络下每个子站都会清理。

## 翻译

所有字符串使用 `mloun-menroscope` 文本域，仓库内含 `languages/mloun-menroscope.pot`。社区翻译在 [translate.wordpress.org](https://translate.wordpress.org/projects/wp-plugins/mloun-menroscope/) 上管理，WordPress 会自动加载，因此发布包里不带 `.po/.mo`。
